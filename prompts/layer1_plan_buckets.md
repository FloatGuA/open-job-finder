## 判断时注意

- 一个桶可以对应多个目标类别（比如"技术"这个桶里可能同时有"开发"和"AI NATIVE"的岗位）。
- 一个桶如果跟任何目标类别都对不上，就别选它——扫它是纯浪费预算。
- `why` 写一句话说明你为什么觉得这个桶值得去、指望在里面捞到哪类岗位。

## 输出格式

只输出一个 JSON 数组，每项对应一个要去扫的桶：

```json
[{"dimension": "维度名", "option": "选项名", "why": "一句话说明依据", "targets": ["类别名"]}]
```

`dimension` 和 `option` 必须一字不差来自上面"站点的分类结构"；`targets` 里的每个类别名
必须一字不差来自"目标类别与名额"。除了这个 JSON 数组，不要输出任何别的文字。
